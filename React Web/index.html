Key features

Everything a small roaster needs to sell online

Built like a real shop, not a mock-up. Each feature works end to end.

  • Customer accounts

    Register, sign in and see order history. Guests can still check out and follow their order through a private link.

  • Admin panel

    Revenue chart, best sellers, low-stock list, product editor and order status updates, all behind a real admin login.

  • Server-side pricing

    Prices, tax, shipping and stock are decided on the server inside a transaction. A tampered browser cannot change a total.

  • Real database

    SQLite with a clean schema, indexes, constraints and seed data. Runs from one file, no database server to install.

  • Secure by default

    Scrypt password hashing, HttpOnly cookies, CSRF checks, rate limits, security headers and a content security policy.

  • Deploy anywhere

    Docker, a Node host, a plain VPS or Vercel. Server has zero npm dependencies, so installs are fast and audits are clean.
